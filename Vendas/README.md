
# Projeto 1 - Dashboard de Análise de Vendas

## Objetivo: 
Desenvolver um dashboard interativo para análise de indicadores de vendas, permitindo acompanhar o desempenho comercial da empresa por categoria, segmento, fabricante, estado e período.

## Ferramentas utilizadas:
- Microsoft Power BI
- Power Query

## Principais indicadores:
- Valor médio das vendas
- Valor total de custo
- Comissão média
- Quantidade de produtos vendidos por categoria
- Quantidade de produtos vendidos por segmento
- Quantidade de produtos vendidos por fabricante
- Quantidade de produtos vendidos por estado
- Quantidade de produtos vendidos por ano

## Principais recursos aplicados:
- Limpeza e transformação de dados
- Criação de indicadores
- Construção de gráficos e cartões
- Organização visual do dashboard
