
# Projeto 2 - Dashboard de RH

## Objetivo:
Desenvolver um dashboard de RH para apoiar a visualização de indicadores relacionados ao quadro de funcionários.

## Ferramentas utilizadas:
- Microsoft Power BI
- Power Query

## Indicadores analisados:
- Total de funcionários
- Salário médio
- Diária média
- Distribuição por função
- Distribuição por idade
- Distribuição por gênero
- Disponibilidade para hora extra

## Principais recursos aplicados:
- Limpeza e transformação de dados
- Criação de indicadores
- Construção de gráficos e cartões
- Organização visual do dashboard
